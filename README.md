# Mindful Password Generator

A Python project that generates personalized and strong passwords based on the user's name.

## Features
- Generates customized passwords
- Uses randomization for stronger security
- User-defined password length
- Mixes characters dynamically

## Concepts Used
- Python Basics
- Strings
- Lists
- Loops
- Functions
- Random Module

## Future Improvements
- Add symbols and special characters
- Add password strength levels
- Add file saving feature
- Convert into a Streamlit web app

## Example

Input:
Enter your name: Avika  
Enter password length: 8

Output:
AvkAiiva
