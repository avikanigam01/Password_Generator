# Mindful Password Generator

A Python-based password generation tool that creates strong, secure, and customizable passwords based on user preferences. The project is designed to promote better password practices while providing a simple and user-friendly experience.

## Features

* Generate strong and randomized passwords
* Customize password length
* Include numbers and special characters
* Input validation for improved reliability
* Exception handling to prevent crashes from invalid inputs

## Technologies Used

* Python
* Random Module
* Exception Handling

## How It Works

1. Enter your name.
2. Choose the desired password length.
3. The program generates a secure password using a combination of user input and random characters.
4. Invalid inputs are handled gracefully using exception handling.
