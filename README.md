# Mindful Password Generator

A Python project that generates personalized and strong passwords based on the user's name.

## Features
- Generates personalized passwords based on the user's name
- Allows user-defined password length
- Adds random digits and special characters
- Validates password length input
- Uses randomization for stronger security
  
## Concepts Used
- Python Basics
- Strings
- Lists
- Loops
- Functions
- Random Module

## Future Improvements
- Ensure at least one digit and one special character in every password
- Add password strength levels
- Add file saving feature
- Convert into a Streamlit web app
